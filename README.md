## 🚀 Local Development & Deployment

### Run Locally
```bash
# Using Python
python3 -m http.server 8000

# Or using Node.js
npx serve .
```
Visit `http://localhost:8000`.

### Deploy to Vercel
```bash
# Deploy to preview
npx vercel

# Deploy directly to production
npx vercel --prod
```
